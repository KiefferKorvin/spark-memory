# Visualization

React and TypeScript use the [Neo4j NVL interactive wrapper](https://neo4j.com/docs/api/nvl/current/functions/_neo4j_nvl_react.InteractiveNvlWrapper.html). Native pan, zoom and drag are enabled. Colors distinguish concepts, documents, sections, chunks, assertions, evidence and sources. Graph states include unvisited, candidate, active, expanded, selected, evidence, pruned and dead-end. Concurrent branch relationships have deterministic branch colors.

The API emits ordered events while workers run. The UI consumes authenticated SSE with `fetch` (so bearer headers work), retries interrupted streams using the last sequence, and skips already-seen sequence numbers. The graph is reconstructed by a pure reducer. Replay and timeline scrubbing run the same reducer over an event prefix; no additional inference occurs. Query IDs reopen durable sessions after a browser restart.

Selecting a node fetches routing summaries, original text and provenance. Manual expansion loads a bounded graph neighborhood; collapse hides descendants in the visualization only. Cross-links remain stored in the property graph. “Show all” restores hidden nodes. Each information need is a root node. Candidates fan out from the node being explored as they are generated; pruned candidates are hidden by default (toolbar toggle), while route edges follow each branch path. Evidence has its own visual node linked to the source node. External discoveries appear as source nodes linked to their need, then to the ingested document that exploration continues from. The toolbar shows the latest event while a query runs. The evidence panel presents coverage and original source excerpts.

NVL transitions newly added nodes and relationships as its force layout settles; the latest traversed edge is highlighted, with a live activity indicator and sequential replay. Reduced-motion preferences disable CSS animation. The timeline and inspector provide text alternatives to graph-only interaction. Layout is responsive to narrow screens.

The frontend uses same-origin `/memory` calls; Vite proxies to port 8010 in development and nginx proxies in Compose. Tokens remain in component memory and are never stored in localStorage or URLs. Do not treat display state as authorization. Trace metadata contains source text, so access to query history must follow the host application's data policy.
