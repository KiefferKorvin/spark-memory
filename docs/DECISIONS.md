# Decisions and boundaries

1. **Standalone `memory/` package.** Existing PAKT infrastructure is Flask/SQLite with account-bound services. Importing those services would couple the reusable module to one application. No working PAKT code was rewritten.
2. **Neo4j as production persistence.** One database stores graph, indexes, trace and usage records. Redis, a second vector database and an external queue are unnecessary for this MVP. In-memory storage is an explicit test/demo adapter only.
3. **Property graph, not a strict tree.** Documents retain containment hierarchy; concepts permit multiple parents and cross-links; assertions retain support and contradictions. UI route edges represent traversal and are not substituted for semantic relationships.
4. **Dedicated Jev endpoint.** The actual OpenRouter typed-decisions protocol is isolated in its navigation adapter. Jev is never called for prose. Strong semantic and embedding models remain configurable.
5. **Bounded supervisor.** A heap with batched concurrent workers is enough for a working exploration loop. Distributed workers and learned routing optimizers are deferred until measured scale requires them.
6. **Conservative coverage.** Sufficiency is judged against the context that can actually reach synthesis, including truncation and valid evidence IDs. Provider failure cannot manufacture covered needs.
7. **Atomic graph commits and immutable content.** Parse/summary failures leave no partially ingested graph; the document hierarchy commits before its concept links, so a concept-linking failure leaves a retrievable, unlinked document. Source revisions and contradictory claims coexist. A database mutation lock prevents concurrent hierarchy-cycle races; it serializes writes and is a known throughput ceiling.
8. **Progressive enrichment.** Basic ingestion stops at concepts and summaries. Claims are extracted on demand or after repeated successful retrieval. External alignment is application-supplied rather than guessed from a particular ontology.
9. **Replay from persisted events.** No animation-specific backend state or separate event broker. The browser replays ordered SSE records using the same reducer as live execution.
10. **Classify instead of discarding, and pay once.** Self-reported model confidence decides taxonomy links. Below `TAXONOMY_MATCH_THRESHOLD`, sound proposals (a new child of valid supplied parents) above `TAXONOMY_PROVISIONAL_THRESHOLD` are kept as provisional LOCAL concepts for review instead of being lost; equivalence (reuse) still needs full confidence, and imported concepts are never modified. Skip verdicts are cached per label within one thesaurus snapshot, threshold pair and prompt version, because a skipped label was otherwise classified and paid for again in every later document. The threshold should be calibrated on labeled decisions (`replay_mapping.py --calibrate`) to keep accepted-link precision at 0.9 or better; the model's confidence is an estimate, not a guarantee.
11. **Honest offline fixtures.** Synthetic concepts and lexical mock decisions demonstrate orchestration without pretending to match Jev or a semantic model. Provider protocol tests use mock HTTP responses. Live inference/database quality requires configured external services.

Known MVP limits: one API process; no tenant ACL (private scopes isolate retrieval, not API access) or durable distributed job resumption; in-process bounded inference cache (not shared across restarts); no automatic external ontology lookup; PDF typography/outline inference and OCR require stronger parsing adapters; source, event and usage retention is operator-managed. The UI inspects neighborhoods up to 500 relationships per request. Neo4j vector index dimensions must match the chosen embedding model. Startup refuses mismatched indexes while vectors are stored (an empty graph rebuilds them); `python -m graph_memory.migrate` rebuilds the indexes and re-embeds nodes and thesaurus. A model change with the same dimension is not detectable and needs a separate database. Vectors are stored only in the indexed `embedding` property, not in node payloads, and candidate similarity is computed in Cypher, so large dimensions do not inflate every row read.
