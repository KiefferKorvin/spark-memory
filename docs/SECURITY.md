# Security boundaries

This is single-tenant infrastructure. The default API command and Compose mappings bind to localhost. Configure the optional shared bearer token before remote access, terminate TLS at your gateway, and implement host-application authentication/authorization before using a shared multi-user memory. PAKT's existing per-user permissions are not automatically imported. Browser/UI content is rendered through React text nodes, not injected HTML.

Sources are untrusted data. Model system prompts explicitly prohibit obeying instructions embedded in queries/documents. Models cannot run tools, choose Cypher or fetch URLs; application code performs every write and fetch. Structured decisions are schema-validated, navigation IDs must belong to the bounded candidate set, evidence references must exist, and enrichment requires verbatim source quotes. These controls constrain actions; they do not prove the semantic truth of model-generated interpretations.

Direct remote ingestion permits HTTPS port 443 on exact configured hostnames only. DNS resolution rejects any non-public address; connections pin a validated address while preserving hostname TLS verification. Redirects are bounded and revalidated. Credentials in URLs, nonstandard ports, control characters and backslashes are rejected. The fetcher ignores proxy environment settings and enforces MIME/byte limits. Wikipedia uses its own fixed allowlist. Application-injected external retrievers are trusted code and must uphold equivalent fetch restrictions.

Input bodies are capped before JSON parsing, base64 limits precede decoding, extracted text/token/section limits follow parsing, and filenames are metadata only. PDF/DOCX parsers run in disposable subprocesses with timeouts; Linux also enforces CPU/address-space limits. Windows lacks that address-space sandbox. DOCX archive expansion is bounded and macro-bearing archives rejected. Encrypted/scanned PDFs without text are rejected. Update parser dependencies and use Linux/container resource quotas for hostile uploads.

Secrets come from environment settings and never enter traces or frontend bundles. `.env` and virtual environments are excluded from build contexts. Provider exceptions return generic errors; usage logs retain counts/status rather than raw authenticated requests. Graph mutations use parameterized values, enum-only relationship labels, endpoint validation and transactions. Hash-based document identity makes ingestion idempotent without dropping independent source provenance.

Traces and original source contents persist in Neo4j; query records and traces are deleted after `TRACE_RETENTION_DAYS`, and backups and database access controls remain the host product's. Private scopes (`user:42`) isolate what one subject's queries read and can be erased with everything recorded for them (`DELETE /memory/scopes/{scope}`), but the client chooses the scope: the bearer token is still the only access control, so a client that can call the API can read any scope. There is no distributed rate limiter or production audit policy. Do not expose an unauthenticated public endpoint.
